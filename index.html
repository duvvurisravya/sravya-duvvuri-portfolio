How I work

The same five stages run through every case study above, scaled to the project's size.

  1. EmpathizeInterviews, surveys and competitor audits to find the real friction.
  2. DefinePersonas, empathy maps and journey maps that name one core problem.
  3. IdeateUser flows and information architecture before any pixels.
  4. DesignWireframes to hi‑fi screens and clickable prototypes in Figma.
  5. TestMaze and moderated testing, then documented iterations.
